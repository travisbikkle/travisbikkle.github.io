# Ubuntu 改鍵


1. 在 Ubuntu Software 中搜索 Gnome Tweaks 並安裝。
2. 點擊 _Keyboard &amp; Mouse_
3. 點擊 _Additional Layout Options_
4. 在彈出的窗口中，勾選 _Ctrl position_ 中的 _Swap Ctrl and Caps Lock_

![ubuntu_swap_keys.png](/images/other/20231017_ubuntu_swap_keys.png)

本文基於 Ubuntu 22.04 LTS 及 Gnome Tweaks 3.34.0 編寫。

&gt; 補充：使用kde更加的方便，該設置已經被集成到系統設置中，無需下載 Gnome Tweaks。
