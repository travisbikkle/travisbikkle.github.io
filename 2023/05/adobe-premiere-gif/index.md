# 使用 Adobe Premiere 制作 GIF 文件


1. 双击左下角媒体浏览器，将视频素材导入
   ![](/images/other/20230531_premiere_1.png)
2. 在左上角编辑窗口，点击如图所示按钮，标记入点与出点（开始与结束）
   ![](/images/other/20230531_premiere_start_end.png)
3. 将左上角的内容拖动到右下角时间轴内
   ![](/images/other/20230531_premiere_drap_and_drop.gif)
4. 右键点击时间轴内的波段，点击取消链接，再次右键，选择清除声音轨道的波纹，以删除声音
   ![](/images/other/20230523_premiere_delete_voice.png)
5. 选择 文件-&gt;导出-&gt;媒体，选择 **动画GIF** 格式，调整大小后导出
   ![](/images/other/20230523_premiere_export_gif.png)
